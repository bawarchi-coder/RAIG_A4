Gender-Fair CV Screening

A plug-in fairness layer for CV screening: it hides gender before an existing tool scores the CVs, then checks whether the shortlist that comes out is fair.

Every candidate, employer and tool here is fictional. The results were produced by the project's own scripts and are stored in this page.

Existing screening tool

The fairness layer runs three ways: as an AI agent skill (Claude Code), as a standalone app, and as an HTTP API for HR software. This page is a static copy of its results for demonstration. A human always makes the hiring decision.
